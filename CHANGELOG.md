# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-29

### Added

- Initial NestJS project scaffolded with the NestJS CLI.
- Husky and Commitlint with Conventional Commits validation.
- GitHub Actions workflows for verify, test, Docker build, and CodeQL.
- Docker multi-stage build.
- Project documentation: README, SECURITY, and OpenCode skill.

### Changed

- Updated package metadata (author, contributors, description, license, repository, engines).
- Upgraded dependencies to latest compatible versions.
